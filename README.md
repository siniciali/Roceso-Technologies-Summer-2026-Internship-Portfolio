# Roceso Technologies — Summer 2026 Internship Portfolio

Index of deliverables produced during a 6-week internship at Roceso
Technologies (Singapore, July–August 2026), under the Laidlaw Research and
Leadership Programme. Each linked repository is private and self-contained,
with its own README documenting scope, status, and validation.

All deliverables below were reviewed and validated by Jane Wang, CEO of
Roceso Technologies.

## Deliverables

| Repository | Area | Summary |
| --- | --- | --- |
| [Roceso_Technologies_Game_Design](git@github.com:siniciali/Roceso_Technologies_Game_Design.git) | Product / Rehab Design | Design and rationale for motor-cognitive coupled rehabilitation games on EsoGLOVE and CygniSENSE Motion — agency-maximising, memory-driven architecture (two-layer: recipe / escape room), plus three game instances and a shared calibration framework. |
| [Roceso_Individual_Finger_EMG_Integration](git@github.com:siniciali/Roceso_Individual_Finger_EMG_Integration.git) | Hardware / R&D | Design constraints and system requirements for individuated finger EMG sensing on EsoGLOVE using NTU on-skin tattoo electrode technology. Written as a handoff document for the incoming EMG engineer. |
| [Roceso_EsoGLOVE_Competitor_Analysis_2026](git@github.com:siniciali/Roceso_EsoGLOVE_Competitor_Analysis_2026.git) | Market Research | Competitive landscape for EsoGLOVE against R-Touch Pro/Elite, Syrebo, Bioliberty Lifeglov, Amadeo, and XFT-2005A/Hand G1 — prepared to support a Ukraine distributor evaluation. |
| [Viely_sizing_analysis](git@github.com:siniciali/Viely_sizing_analysis.git) | Product Analytics | Statistical analysis of 467 patient leg measurements for Viely compression stockings — identifies a calf/ankle shape gap over a size gap, and recommends a wide-calf variant. |
| [Viely_tracker_system](git@github.com:siniciali/Viely_tracker_system.git) | Automation / Ops | Google Apps Script system syncing the Viely order tracker to Google Contacts and generating a rules-based WhatsApp follow-up queue with repurchase suppression. |

## Reading notes

- Each repository's own README is the source of truth for status and
  validation — this index only summarizes.
- Where a repository is marked "draft" or "handoff" internally, treat it as
  such regardless of what's implied here.

  confidential — see their individual READMEs before sharing.
