# Roceso Technologies — Summer 2026 Internship Portfolio

Index of deliverables produced during a 6-week internship at Roceso
Technologies (Singapore, July–August 2026), under the Laidlaw Research and
Leadership Programme. Each linked repository is private, with its own README documenting scope, status, and validation.

All deliverables below were reviewed and validated by Jane Wang, CEO of
Roceso Technologies.

## Deliverables

| Repository | Area | Summary |
| --- | --- | --- |
| [Roceso_Technologies_Game_Design](git@github.com:siniciali/Roceso_Technologies_Game_Design.git) | Product / Rehab Design | Design and rationale for motor-cognitive coupled rehabilitation games on EsoGLOVE and CygniSENSE Motion. Work on an agency-maximising, memory-driven architecture. |
| [Roceso_Individual_Finger_EMG_Integration](git@github.com:siniciali/Roceso_Individual_Finger_EMG_Integration.git) | Hardware / R&D | Design constraints and system requirements for individuated finger EMG sensing on EsoGLOVE. |
| [Roceso_EsoGLOVE_Competitor_Analysis_2026](git@github.com:siniciali/Roceso_EsoGLOVE_Competitor_Analysis_2026.git) | Market Research | Competitive landscape for EsoGLOVE. |
| [Viely_sizing_analysis](git@github.com:siniciali/Viely_sizing_analysis.git) | Product Analytics | Statistical analysis of 467 patient leg measurements for Viely compression stockings. Includes new sizing recommendations. |
| [Viely_tracker_system](git@github.com:siniciali/Viely_tracker_system.git) | Automation / Ops | Google Apps Script system syncing the Viely order tracker to Google Contacts and generating a rules-based WhatsApp follow-up queue. |

## Context

Internship supervised by Jane Wang. Work spanned QMS/ISO 13485
documentation, control box assembly, rehabilitation game design, market and
competitor analysis, and internal tooling for a partner product line
(Viely).
